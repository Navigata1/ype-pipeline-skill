# YPE Pipeline Skill

**YPE (YouTube Pipeline Experience)** is a structured YouTube playlist intelligence pipeline for turning videos and playlists into verified knowledge assets:

- transcript-derived timestamp maps
- visual frame capture
- vision analysis
- enhanced transcripts
- intelligence reports
- infographics
- category/master compilations
- NotebookLM/browser integration when required
- optional publication packages

Current version: **YPE v7.2**

## Current Skill

The canonical skill is [`SKILL.md`](./SKILL.md).

## Core v7.2 Philosophy

YPE v7.2 combines:

- the speed and directness of older v4/v5 runs,
- the evidence discipline of v6.x EVS validation,
- the corrected curated-drop logic from the AgentPie failure audit.

Small hand-selected batches default to Tier 1 full treatment. Large playlist sweeps use tiering normally.
