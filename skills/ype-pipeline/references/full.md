# Full YPE contract

Complete the quick contract first, then deepen it. The historical v7.2 specification is preserved separately as source evidence; its optional deletion/Gemini/date-named-notebook instructions do not override current retention, native image or playlist-reuse requirements.

1. Derive `moments.json` from the whole transcript. Include argument turns, demos, diagrams, transitions and any high-value UI/code sequence. Give each interval a concrete reason and requested capture times. High-importance intervals need at least three distinct captures; ordinary intervals need at least one. Bind the map to transcript/source hashes.
2. Run `capture-moments RUN VIDEO_ID`. Inspect captures from every mapped interval, expanding relevant originals. The map's completeness remains a semantic judgment; the machine checks only that claimed moments have real, in-range, decoded evidence.
3. Write an **expanded timed source account** retaining every meaningful section, demonstration, procedure, example and qualification, and integrating clearly labeled inspected visual context within the relevant timed sections. Express analysis in your own words; preserve original downloaded captions separately and cite the source. The 500-word floor only catches empty substitutes and is not a target or completeness test. Write a separate **intelligence report** (minimum 350 words); keep company-specific application in a downstream report. Record cue-range/section coverage and inspected frames in `enhanced-source-map.json`, and bind that map in `full-review.json`. Semantic/source-fidelity acceptance remains a distinct review.
4. Write an infographic request from validated claims. Use the host's actual native GPT image-generation tool; preserve the returned original and request text. Inspect labels, claim accuracy, hierarchy and legibility. Record the tool call reference, time, input analysis hash and image hash/dimensions in `infographic.json`. If the host lacks the tool, mark awaiting-image-adapter; do not substitute a text card or claim completion. Full defaults to one per-video infographic; a deliberately different visual scope needs an explicit updated contract, not a silent reduction.
5. Create a substantial `master-compilation.md` and `categories.json` covering every video exactly once in primary categories (cross-links allowed). Preserve disagreements, uncertainty, provenance and actionable conclusions. Bind synthesis to all current analysis hashes. Optional category/master visuals, books, mind maps and data tables are additional requested outputs; audio and slides remain the core NotebookLM deliverables.
6. Package the actual substance for NotebookLM and execute its browser adapter. Rich HTML stays the human report. Prefer one clearly titled source account per video where capacity permits. Pack expanded timed accounts and reviewed visual observations; use original YouTube sources as provider imports when available. `--caption-mode references` retains original captions locally and avoids repeating them in the supplemental packet. With `--community`, each video's packet carries its scored `community.md` (paraphrased notes, never raw comments); with `--synthesis`, the claim matrix follows the master compilation. Record unavailable provider imports and the actual source-account alternative. No upload of the raw-media library is implied.
7. Verify local deliverables, source ingestion and both Studio outputs independently. A queued image/deck/audio job remains pending; leave exact artifact identifiers and resume steps. Do not say “full YPE complete” until every requested stage is satisfied.

For a huge playlist, finish sequential local batches before expanding remote work. Source packing reduces notebook source slots, not information. If the measured packet budget exceeds the current account allowance, stop and create a deliberate named-volume plan. Automatic remote sharding is not implemented by this CLI. Native generation and browser work require an active agent; this skill is not a stand-alone unattended media farm.
