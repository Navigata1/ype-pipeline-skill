# Full YPE contract

Complete the quick evidence contract, then deepen it under `source-quality.md`. Each video must remain independently understandable before cross-video or project synthesis. The historical v7.2 specification is preserved separately as source evidence; its optional deletion/Gemini/date-named-notebook instructions do not override current retention, native image or playlist-reuse requirements.

1. Derive `moments.json` from the whole transcript. Include argument turns, demos, diagrams, transitions and any high-value UI/code sequence. Give each interval a concrete reason and requested capture times. High-importance intervals need at least three distinct captures; ordinary intervals need at least one. Bind the map to transcript/source hashes.
2. Run `capture-moments RUN VIDEO_ID`. Inspect captures from every mapped interval, expanding relevant originals. The map's completeness remains a semantic judgment; the machine checks only that claimed moments have real, in-range, decoded evidence.
3. Write an **expanded timed source account** retaining every meaningful section, demonstration, procedure, example and qualification, and integrating clearly labeled inspected visual context within the relevant timed sections. Preserve the complete cleaned spoken substance section by section, including examples, displayed procedures and qualifications; a synopsis plus a caption appendix is insufficient. Use faithful wording/paraphrase, preserve original downloaded captions separately and cite the source. The 500-word floor only catches empty substitutes and is not a target or completeness test. Write a separate **intelligence report** (minimum 350 words); keep all project application in the separate `project-applications.md`. Record cue-range/section coverage and inspected frames in `enhanced-source-map.json`, and bind that map in `full-review.json`. Semantic/source-fidelity acceptance remains a distinct review.
4. Build `infographic-brief.json` from the full expanded account: inventory the major source concepts with evidence and describe how each will appear. Choose a composition because it fits the actual relationships. Write the image request from this brief. Use the host's actual native GPT image-generation tool; preserve the returned original and request text. Apply the source coverage, relationship, factual label, legibility and source-specificity checks in `source-quality.md`; bind both the brief and expanded account in the image receipt. A generic icon/arrow chain does not pass merely because it looks polished. Record the tool call reference, time, input analysis hash and image hash/dimensions in `infographic.json`. If the host lacks the tool, mark awaiting-image-adapter; do not substitute a text card or claim completion. Full defaults to one per-video infographic; a deliberately different visual scope needs an explicit updated contract, not a silent reduction.
5. Create a substantial `master-compilation.md` and `categories.json` covering every video exactly once in primary categories (cross-links allowed). Preserve disagreements, uncertainty, provenance and actionable conclusions. Bind synthesis to all current analysis hashes. Optional category/master visuals, books, mind maps and data tables are additional requested outputs; audio and slides remain the core NotebookLM deliverables.
6. Package the actual substance for NotebookLM and execute its browser adapter. Rich HTML stays the human report. New full runs require exactly one clearly titled source account per unique video. Package the expanded account and reviewed visual observations. Cross-video synthesis, community reception and project applications remain separate local reports; importing them into a notebook is a separately requested extension. `--caption-mode references` retains original captions locally and avoids repeating them in the supplemental packet. An original video URL is a reference, not a second required source. Never combine videos, split one video or summarize substance to fit a local budget. If a limit is hit, checkpoint it and plan an explicit capacity/volume exception. No upload of the raw-media library is implied.
7. Review artifact integrity and semantic/visual acceptance separately, then verify local deliverables, source ingestion and both Studio outputs independently. A queued image/deck/audio job remains pending; leave exact artifact identifiers and resume steps. Do not say “full YPE complete” until every requested stage is satisfied.

For a huge playlist, finish sequential local batches before expanding remote work. Keep one source per video within each planned volume. If the measured packet budget exceeds the current account allowance, stop and create a deliberate named-volume plan. Automatic remote sharding is not implemented by this CLI. Native generation and browser work require an active agent; this skill is not a stand-alone unattended media farm.
